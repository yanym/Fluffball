# User-Provided Assets

This directory contains the original material supplied by the user. These files are provenance inputs only: the app never reads or bundles them at runtime.

- `SourceVideos/` preserves original green-screen action footage by view and action.
- `SourceImagesForAIVideo/originals/` preserves original identity, posture, and view photographs.

Do not overwrite these files with keyed, normalized, retouched, generated, or compressed derivatives. Put every derivative under `../Generated/` and put final app resources under `Sources/Furball2D/Assets/`.
