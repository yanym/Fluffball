# Nina source workspace

This folder owns every non-runtime asset associated with Nina.

- `UserProvided/` preserves the original photos and green-screen videos exactly as supplied.
- `Generated/` contains prepared identity views, generated sprite sources, intermediate files, and QA evidence.

Nina's bundled Pet Pack is built separately at `Sources/Furball2D/Assets/Pets/Nina/`. Do not mix another pet's photos, generated rows, clips, or QA into this directory.
